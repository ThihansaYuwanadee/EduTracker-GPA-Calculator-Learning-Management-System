## 📌 Overview
EduTracker is a full-stack web application designed to manage student data, academic activities, and performance tracking.

## Key Features
- Secure authentication and user management  
- Dynamic class management (add/remove students)  
- Real-time GPA calculation  
- Interactive calendar for event management  
- Responsive and user-friendly UI  

## Tech Stack
- MongoDB  
- Express.js  
- React.js  
- Node.js  

## Key Contributions
- Developed full-stack architecture for academic management system  
- Implemented secure authentication and role-based access  
- Built dynamic student and class management features  
- Designed real-time GPA calculation logic  
- Created interactive calendar interface for event tracking  

## Outcome
A scalable system that simplifies student management, improves academic tracking, and enhances user experience through an interactive interface.
